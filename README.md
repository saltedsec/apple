# 🍎 사과게임

드래그로 숫자를 이어 합이 10의 배수가 되면 점수를 얻는 1분 챌린지입니다.

## 게임 소개

8×8 보드의 사과 위에 표시된 숫자를 상하좌우 또는 대각선으로 이어 선택하세요. 선택 합계가 화면에 표시되며, 합이 10, 20, 30 등 10의 배수가 되도록 손을 떼면 해당 합만큼 점수를 얻습니다. 사과 보상 애니메이션에는 획득 점수가 아이콘 위에 표시됩니다. 사라진 숫자 위의 숫자는 아래로 내려오고, 빈칸은 새 숫자로 채워집니다. 점수 100점을 넘기면 축포가 터지고, 최고 점수를 경신하면 긴 꽃가루 효과가 나옵니다. 60초 동안 최고 점수에 도전해보세요.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript로 게임 화면과 동작을 구현했습니다. 포인터 이벤트를 사용해 마우스와 터치 드래그를 지원하며, 최고 점수는 브라우저의 `localStorage`에 저장합니다.

## 실행 방법

저장소를 내려받은 다음 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

실습 예시의 2분 제한을 요청에 맞춰 1분으로 변경하고, 한 파일에 담는 대신 HTML/CSS/JS 세 파일로 분리했습니다. 숫자를 사과 아이콘 위에 표시하고, 목표 합을 10뿐 아니라 모든 10의 배수로 확장했습니다. 최고 점수 저장, 열 단위 낙하, 점수 애니메이션, 최고 기록 꽃가루와 100점 초과 달성 축포 효과, 반응형 화면을 추가했습니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
