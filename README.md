# 🍎 사과게임

사과 위의 숫자를 드래그로 이어 합을 10의 배수로 만들고, 60초 안에 최고 점수에 도전하는 게임입니다.

## 게임 소개

8×8 보드의 각 사과에는 1~9의 숫자가 표시됩니다. 상하좌우 또는 대각선으로 인접한 사과를 드래그해 이어 선택하고, 선택한 합이 10, 20, 30 등 10의 배수가 되면 손을 떼세요. 합계만큼 점수를 얻고 선택한 사과는 사라집니다. 위쪽 사과가 아래로 내려오며 빈칸은 새 숫자로 채워집니다.

- 선택 중 현재 합계와 다음 목표 합계를 확인할 수 있습니다.
- 성공하면 획득 점수와 사과 아이콘이 보상 애니메이션으로 나타납니다.
- 최고 점수를 경신하면 화려한 꽃가루가 흩날립니다.
- 점수가 100점을 초과하면 축포가 터집니다.
- 마우스와 터치 입력을 지원합니다.
- 최고 점수는 브라우저에 저장되어 다음 방문에도 유지됩니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript로 만들었으며, 화면 구조·스타일·게임 로직을 각각 `index.html`, `style.css`, `script.js`로 분리했습니다. 포인터 이벤트로 드래그 입력을 처리하고, 최고 점수 저장에는 브라우저의 `localStorage`를 사용합니다.

## 실행 방법

저장소를 내려받은 후 `index.html`을 브라우저에서 여세요. 별도 설치나 빌드 없이 바로 플레이할 수 있습니다.

## 커스터마이징한 부분

실습 예시에서 게임 시간을 2분에서 1분으로 조정하고, 단일 파일 대신 HTML/CSS/JS 파일로 분리했습니다. 숫자를 사과 위에 표시하고, 목표를 합 10에서 모든 10의 배수로 확장했습니다. 열 단위 사과 낙하, 선택 합계와 보상 애니메이션, 최고 점수 저장, 기록 경신 꽃가루, 100점 초과 축포, 반응형 화면을 추가했습니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
